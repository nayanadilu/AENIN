# Citation

Please cite the accepted AENIN article when using this repository.

Add the final publisher citation here once the definitive bibliographic
metadata and DOI are available.

Suggested placeholder format:

```text
Author(s). "AENIN: Adaptive Edge-Node Interaction Network."
Journal, year. DOI: ...
```

A `CITATION.cff` file should be added only after the exact author list, article
title, journal, year, and DOI have been verified.
