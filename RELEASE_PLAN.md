# Release Plan

## Current stage — Research preview

The repository contains only high-level documentation and non-sensitive public
utilities.

## After article acceptance

The repository is intended to be expanded with the implementation and
reproducibility material associated with the accepted study.

Before that release, the authors should:

1. remove local paths, credentials, temporary files, and private data;
2. verify dataset redistribution restrictions;
3. clean and document the research code;
4. freeze the accepted experimental configuration;
5. add reproducibility instructions;
6. add the article citation and version tag; and
7. archive a release if required by the journal.
